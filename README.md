## 标题与段落：搭建文档结构
### 作用
标题用来**分级组织内容**，帮助读者快速定位章节；段落用来分段，避免大段文字挤在一起。
- `#` 一级标题：文档大题目（全文只有1个）
- `##` 二级标题：大章节
- `###` 三级标题：小节
段落之间空一行，实现换行区分，提升可读性。

### 示例
# 一级标题（文档总标题）
## 二级标题（大章节）
### 三级标题（小节）
普通段落文字，一段描述一件事。

另起一个段落，和上一段中间空一行。

- `反引号`：标记命令、文件名、代码关键词（行内代码）

## 链接与图片：相对路径 vs 绝对路径
### 语法模板
链接：`[显示文字](链接地址)`
图片：`![图片描述](图片地址)`

#### 1. 相对路径（推荐用于同项目、同目录文档）
> 适用场景：仓库内部文件，移动整个文件夹链接不会失效
- 同目录其他文档：`[查看更多文档](./guide.md)`
- 子文件夹图片：`![截图](./assets/demo.png)`

#### 2. 绝对路径
> 适用场景：外部网页、互联网图片；文件移动后容易失效
- 网页链接：`[Markdown教程官网](https://www.markdownguide.org/)`
- 网络图片：`![markdown图标](https://xxx/demo.jpg)`

> 对比总结：写项目README优先**相对路径**；引用外网资源用绝对路径。

## 速记
1. **标题+段落组织重点**
用一级标题作为文档名，二级标题划分大模块，三级标题细分小节；段落之间空行。读者可以看目录/标题快速扫读，找到想看的章节，不用通读全文。

2. **句子中突出重点、命令、文件名**
- 重点文字：`**加粗**`
- 命令/文件名：`` `单行反引号` ``，在正文里和普通文字区分。

3. **不同列表场景**
- 罗列事项（无先后）：无序列表 `-`
- 操作步骤（顺序不能乱）：有序数字列表 `1. 2.`
- 待办任务勾选框：`- [ ]` 任务列表

4. **链接图片；相对/绝对路径**
- 链接：`[文字](地址)`，图片：`![alt文字](地址)`
- **相对路径**：项目内的文档、图片，跟着文件夹一起拷贝不会坏，项目README首选；`./`代表当前目录
- **绝对路径**：完整网址，用于外部网页、网上图片；一旦原图删除链接失效
